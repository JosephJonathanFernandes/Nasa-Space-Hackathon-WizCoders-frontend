# Testing Guidelines

- All new features must include unit tests in `tests/`.
- Use [Vitest](https://vitest.dev/) for fast, modern unit/integration testing.
- Use [React Testing Library](https://testing-library.com/docs/react-testing-library/intro/) for UI tests.
- Target 80%+ code coverage for all core logic.

## Example Test Command

```
npm run test
```
